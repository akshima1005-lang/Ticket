# PROJECT STATEMENT

## Project Title

**Ticket Booking System**

## 1. Project Description

The **Ticket Booking System** is a Python-based application designed to simulate the basic process of booking tickets. The system allows users to select a destination, enter passenger details, specify the number of tickets, and calculate the total booking amount.

The project is developed using **Python** and focuses on implementing basic programming concepts such as variables, user input, conditional statements, arithmetic operations, and data validation.

The main purpose of this project is to provide a simple and easy-to-use ticket booking system while helping students understand how programming concepts can be applied to a real-world problem.

---

## 2. Project Scope

The scope of the Ticket Booking System includes providing basic ticket booking functionality for users.

### The system will:

* Display a list of available destinations.
* Allow users to select a destination.
* Accept passenger information.
* Allow users to enter the number of tickets required.
* Calculate the total ticket cost automatically.
* Display complete booking details.
* Confirm successful ticket booking.
* Handle invalid destination selections.

### The project is intended for:

* Students learning Python programming.
* Beginners working on programming projects.
* Academic and educational purposes.
* Demonstrating basic ticket booking functionality.

---

## 3. High-Level Features

### 3.1 Destination Selection

The system provides users with a list of available destinations. Users can select their desired destination by entering the corresponding option.

### 3.2 Passenger Details

The system collects basic passenger information, such as:

* Passenger name
* Passenger age

### 3.3 Ticket Selection

Users can specify the number of tickets they want to book.

### 3.4 Automatic Fare Calculation

The system calculates the total cost based on the selected destination and number of tickets.

**Formula:**

```text
Total Amount = Ticket Price × Number of Tickets
```

### 3.5 Booking Details

After completing the booking, the system displays:

* Passenger name
* Passenger age
* Selected destination
* Ticket price
* Number of tickets
* Total amount

### 3.6 Booking Confirmation

The system displays a confirmation message when the ticket has been successfully booked.

### 3.7 Input Validation

The system checks user selections and displays an appropriate message when an invalid destination is entered.
